# WILDBOUND: Primal Age

First-person prehistoric survival (late Paleolithic). Godot 4.7 · Phase 1 graybox prototype.

- Run: `godot --path .` (or open in the Godot editor and press F5)
- Tests: `./tests/run_tests.sh`
- Design: `WILDBOUND_Primal_Age_GDD.docx`
- Architecture: `docs/ARCHITECTURE.md` · Phase reports & manual test scripts: `docs/PHASE1_DELIVERY.md`, `docs/PHASE2A_DELIVERY.md` · Assets: `docs/ASSET_BIBLE.md`

Controls (default): WASD move · Shift sprint · C crouch · Space jump · E interact (hold) · R secondary · LMB swing/place ·
RMB cancel · 1–6 hotbar · Tab inventory · J journal · B build menu · G toggle snapping · Esc pause. All remappable in Settings.
